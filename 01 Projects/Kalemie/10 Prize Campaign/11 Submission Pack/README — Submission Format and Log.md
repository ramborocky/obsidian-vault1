## What was applied

| Convention | Setting | Why |
| --- | --- | --- |
| **Paragraphs** | First-line indent 1.27cm, **no blank line between** | Block paragraphs read as web post, not fiction |
| **Indent method** | Paragraph style, **not Tab, not spaces** | Tabs break in conversion; spaces are worse. The most common amateur tell |
| **First paragraph** | Flush left | Convention: no indent at an opening or after a break |
| **After scene break** | Flush left | Same rule |
| **Scene breaks** | Centred `#` on its own line | A bare blank line vanishes at a page break. **Beat of My Hurt depends on its 12 breaks completely** |
| **Spacing** | Double, 1.15 nowhere | Standard |
| **Font** | **Arial 12pt** (Chantal) · Times New Roman (Beat) | **Rule 3n specifies Arial for English entries.** Times New Roman is the convention for magazines |
| **First page** | Title, then **word count** | **Rule 3k** requires both |
| **Page** | A4, 2.54cm margins, **all pages numbered** | Rule 3n requires numbering |
| **Running head** | *Title / page number* | A lost page is a lost story |
| **File name** | **The story title only** | **Rule 3k** — not `Commonwealth Story`, not generic, not `- submission` |
| **Author name** | **Absent everywhere** | **Rule 3l** — *"must not be given anywhere on the uploaded document"*. Not in the header, not on the title, not in file properties |

**Both files are anonymous.** Check your own Word copy does not add your name back into document properties when you save — File → Info → Inspect Document if you edit and re-save.

## Before you send — the checklist

**Read the prize's own rules first. Their spec beats every convention above.** If their form specifies a font, a file type, or plain text pasted into a box, follow that and ignore this page.

```
[ ] Prize rules read this cycle, not last cycle
[ ] Entry window confirmed open, deadline noted with a date
[ ] Word count inside 2,000–5,000 (Chantal ~3,570 ✅)
[ ] Story is unpublished per their definition — check whether a blog or
    workshop post counts as published for them
[ ] Eligibility confirmed: citizenship / residency
[ ] Name appears nowhere in the manuscript
[ ] File properties checked for your name after any re-save
[ ] Opened the file and looked at it
[ ] Read the first page aloud one last time
[ ] Fee paid if applicable — YOU do this, never me, never through here
[ ] Confirmation email saved
[ ] Logged below
```

> **Payments are yours alone.** I do not enter card details, banking or mobile-money credentials, or submit forms on your behalf. That is a standing limit and it does not move.

## Rebuilding these files

The source of truth is the markdown, never the .docx. When a draft changes:

1. Edit the markdown in `01 Story Brain/` or `00The beat of my hurt/`
2. Say **"rebuild the submission files"**
3. Both .docx are regenerated from the current prose with the same formatting

**Never edit the .docx by hand.** The moment you do, the vault and the submission disagree and you will not know which one you sent.
