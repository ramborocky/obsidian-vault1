# zz_Non-Relevant — Archive

*Named to sort last and stay out of the way. Nothing here was deleted — everything was moved, and everything is explained below. If you're looking for the current master draft, it's `STORY PROGRESSION & DRAFTS/DRAFTS/KALEMIE-Draft_with_AI_Questions.md` — that's the file this cleanup was built around.*

## Why this exists

On 2026-07-23, a craft-test pass on the actual draft prose surfaced that the vault had accumulated several superseded/duplicate versions of the same material across three different folders, plus a handful of genuinely stray files (empty stubs, a raw AI-chat text dump, a duplicate command-center doc). This folder is where that material went instead of being deleted.

## superseded-drafts/

- **`00 Draft.md.md`** (was `STORY PROGRESSION & DRAFTS/DRAFTS/`) — the original master draft. Superseded by `KALEMIE-Draft_with_AI_Questions.md`, which contains the same events (BMW/Jean Luc, birthday watermelon, rain/twenty-seconds, police station/envelope) with tighter prose (14.2 avg words/sentence and heavy "was"/banned-word density here, vs. 9.9 avg and far fewer violations there) and adds the retrospective "Option C" opening this draft never had.
- **`Scenes-Story progression/`** (was `STORY PROGRESSION & DRAFTS/`) — an earlier, abandoned experiment at the same "retrospective opening" idea. Its Scene 1 opens with Djamela already missing and Morisho already arrested — same instinct as "Option C" in the master draft, but diverged on specifics (a Commodore 64 instead of the motherboard, an added "fat Belgian" character, explicit "assault" framing instead of the vaguer, better dread of "wamemchukua... anahusika na kifo cha msichana"). Scenes 2–7 in this folder were empty placeholders — the real Scene 2–7 content now lives fully written inside the master draft. **The Commodore-64 / fat-Belgian / trafficking-ring idea is flagged as trunk material** in [[Collection Tracker]] — it didn't fit Kalemie, but it's a real idea worth another story in the cycle.
- **`scenes.md.md`** (was `09 AI Laboratory/`) — an earlier, shorter version of the same Scene 1–7 breakdown now fully present (with the added opening and Structural Notes) inside the master draft.
