# 6 · What would I have to believe for this to be a bad idea?

**When the mama ntilie idea arrived, my first instinct was to go looking for reasons it works.** That instinct is worthless. Enthusiasm supplies evidence for anything, and search engines are extremely good at finding support for a thing you have already decided.

So invert it. Not *is this good* — **what would have to be true for this to be a disaster, and how would I know?**

For the training idea the inversion wrote its own research plan in four lines:
1. It would be bad if someone had already tried it at scale and failed. *(Kippa: $14M, 500,000 users, app dark.)*
2. It would be bad if the training were already free. *(Vodacom, the BOT Academy with WFP and the Mastercard Foundation, CRDB's Malkia.)*
3. It would be bad if a funded competitor were already local. *(Ramani.io: $34M and a Bank of Tanzania lending licence, in Dar.)*
4. It would be bad if the customer had no money. *(A few thousand shillings of daily margin.)*

**Four for four, in one afternoon.** Not one of those would have surfaced from asking whether the idea was good, because each is a reason to stop, and a search for validation does not return reasons to stop.

The inversion has a second use that matters more. Run it on the plan you have *chosen*, not just the one you are rejecting. What would make the practice a disaster? *The credential turns out to need an employer.* Ask, and there it was.

Charlie Munger's version is blunter: invert, always invert. Tell me where I'm going to die so I don't go there.

> **The question:** what would have to be true for this to fail badly — and which of those can I check this week for the price of an afternoon?

The reason nobody does this is emotional, not intellectual. You have to want the answer more than you want the idea, and by the time an idea is exciting enough to research, that is usually no longer true.
