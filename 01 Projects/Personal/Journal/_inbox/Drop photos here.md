# Drop Photos Here

Whatever gets a photo of a handwritten journal page into this folder works:

- **Cloud sync** — point your phone's camera-upload (OneDrive/Google Drive/Dropbox) at a folder that also syncs to this path on this PC.
- **Manual drop** — AirDrop, email-to-self, USB, whatever — just save the file into this folder.
- **Paste straight into chat** — skip this folder entirely; paste the photo directly into a message to Claude and it reads it in that same turn.

Once a photo is here, tell Claude to "process my journal inbox." See `../README.md` for the full pipeline. Processed originals move to `processed/YYYY-MM/` — nothing gets deleted.
